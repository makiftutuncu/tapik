# Module tapik

tapik defines type-safe HTTP endpoints as ordinary Kotlin values and generates OpenAPI documents, Spring
RestClient clients, and Spring WebMVC servers at build time.

This reference combines the public APIs from tapik's Maven modules. Start with the `dev.akif.tapik` package for the core
DSL, then follow the `format`, `target`, and `plugin` packages for optional integrations. The standalone Gradle plugin's
public API is documented in its own Dokka HTML archive, published with `dev.akif:tapik-plugin-gradle`.
