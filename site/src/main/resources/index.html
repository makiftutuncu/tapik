Type-safe APIs in Kotlin

Define endpoints once.
Let the build check the rest.

Define HTTP endpoints as Kotlin values. tapik checks definitions as they are built and generates API documentation, clients, and server interfaces from the same endpoints. Generation reports when a selected integration cannot support an endpoint feature.

A small endpoint

Choose what to generate

Define an API in Kotlin, then choose an output in your build. Use generated server interfaces in your handlers or generated clients in your application.

Open the runnable example → 
object Books : Api() {
    val list by
        get(root / "books")
            .output(
                Status.Ok with
                    jsonBody<List<Book>>()
            )
}
