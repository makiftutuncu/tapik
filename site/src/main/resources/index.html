Type-safe APIs in Kotlin

Define endpoints once.
Let the build check the rest.

tapik represents HTTP endpoints as ordinary Kotlin values. Their structure stays in their types, and tapik checks invalid definitions during compilation and generates outputs without making OpenAPI the source of truth.

Generate many targets

Produce OpenAPI, Spring RestClient clients, and Spring WebMVC servers from the same endpoints.

A small endpoint

Ordinary values, precise types

Define an API in one artifact, then select targets in the consuming Maven build. tapik generates source early enough for application code to implement servers or invoke clients.

Open the runnable example → 
object Books : Api() {
    val list by
        get(root / "books")
            .output(
                Status.Ok with
                    jsonBody<List<Book>>()
            )
}
