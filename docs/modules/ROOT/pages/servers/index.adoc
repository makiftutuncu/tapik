= Implement servers
:description: Implement typed HTTP servers from tapik contracts.

Server targets generate a typed interface for application-owned handlers and a framework-specific adapter that owns
wire decoding, response encoding, and routing integration. The handler boundary should remain focused on Kotlin values
even as additional server stacks are introduced.

The first server integration is xref:servers/spring-webmvc.adoc[Spring WebMVC]. Future server stacks belong alongside
it and can generate their own adapters around the same contract information.

Applications usually generate servers from a compiled contract dependency during `generate-sources`, allowing their
ordinary Kotlin source to implement the generated handler interface.
