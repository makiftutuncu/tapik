= Implement servers
:description: Implement typed HTTP servers from tapik endpoints.

tapik generates a Kotlin interface for your server handler. The supported Spring WebMVC integration also generates an
adapter that connects HTTP requests and responses to that handler.

Read the xref:servers/spring-webmvc.adoc[Spring WebMVC guide] for setup, handler implementation, and request handling.

When application source needs to implement the generated interface, put the endpoints in a separate compiled API
module. The integration guide explains this setup.
