= Generate API documentation
:description: Create API documentation from tapik endpoints.

tapik generates API documentation from the same Kotlin endpoints used for clients and servers. The generated document
does not replace or change those endpoint definitions.

The supported documentation format is xref:documentation/openapi.adoc[OpenAPI]. That guide explains how to generate a
document and which endpoint features it can describe.

See the xref:reference/maven.adoc[Maven reference] or xref:reference/gradle.adoc[Gradle reference] for build setup.
