= Define endpoints
:description: Define type-safe HTTP endpoints as ordinary Kotlin values with tapik.
:page-aliases: user-guide.adoc, custom-types.adoc, project-layout-and-discovery.adoc

Define each endpoint as an immutable Kotlin value. Kotlin infers a type that keeps the endpoint's structure for
documentation, clients, and servers.

You normally do not write an `Endpoint` type explicitly. Kotlin infers one that keeps the path and query values,
headers, request body, response alternatives, and API property binding.
