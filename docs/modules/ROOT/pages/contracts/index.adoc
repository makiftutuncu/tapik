= Define contracts
:description: Define type-safe HTTP contracts as ordinary Kotlin values with tapik.
:page-aliases: user-guide.adoc, custom-types.adoc, project-layout-and-discovery.adoc

tapik contracts are ordinary, immutable Kotlin values. You describe the structure of an HTTP API once, retain that
structure in the inferred types, and let generation targets decide how to turn it into documentation, clients, or
servers.

You normally do not write an `Endpoint` type explicitly. Kotlin infers a type containing the path and query values,
headers, request body, every response alternative, and whether the endpoint has been bound to an API property.
