`Api()` uses the type's simple name as its `apiId`. Pass a non-blank `apiId` when you want another API name. The base
class has no `id` member, so endpoint definitions can use that name for a resource path variable.

== Endpoint identity

Declare endpoints inside an API using delegated properties. The API ID and property name form each endpoint's stable
ID. The example defines `AuthorRoutes.list` and `AuthorRoutes.get`.

Property delegation registers each endpoint during API initialization and keeps declaration order. The property keeps
its precise inferred type. `Api.endpoints` provides an ordered list for generation, but its broad element type does not
show each endpoint's full type.

[IMPORTANT]
====
APIs selected for generation must be public. Keep endpoint properties public when generated source needs to reach them
through the API instance.
====

== Start with a method

Inside an API, `get`, `head`, `post`, `put`, `patch`, `delete`, `connect`, `options`, `trace`, and `query` start an
endpoint. Each takes a `Uri` and optional summary, description, and initial tag set.

A fresh endpoint has useful defaults:

* no request headers;
* no request body input;
* one empty `200 OK` response.

That makes `val list by get(root / "authors")` complete. Add only the parts that differ.

== Draft and ready values

Method builders produce an immutable draft endpoint. Each modifier returns another draft value, so Kotlin functions
can share and refine partial definitions. Delegating the final value registers it as a ready endpoint and assigns its
ID. Ready endpoints cannot be modified.

The inferred type has this general shape:

[source,kotlin]
----
Endpoint<Paths, Queries, Headers, Input, Outputs, EndpointState>
----

The actual type arguments are more specific. Ordered endpoint parts use tuples that preserve each element's type and
position, up to eight elements. A ninth path value, query, header, body alternative, or response alternative has no DSL
builder and fails to compile.

Generation reads these endpoint values and types directly. tapik does not create a second copy of their definitions.
