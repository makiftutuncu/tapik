= Runnable example
:description: Run tapik's library API example with Maven or Gradle.

The example defines library endpoints in one project and uses them from a separate application project. The Maven and
Gradle builds use the same Kotlin source:

`example-contract`:: Defines author, book, and catalog endpoints. It also generates OpenAPI in the same project.
`example-application`:: Uses those endpoints to generate OpenAPI, clients, and server interfaces. Its handlers implement
the generated interfaces, and its tests call a generated client.

Build the Maven examples with `./mvnw verify`. The Gradle example uses the same sources and covers both same-project
and compiled API generation.

Start with the xref:getting-started.adoc[quickstart], then use the
xref:reference/gradle.adoc[Gradle reference] for Gradle setup.
