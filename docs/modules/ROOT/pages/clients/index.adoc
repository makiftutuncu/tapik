= Generate clients
:description: Generate typed HTTP clients from tapik endpoints.

tapik generates typed Kotlin clients from your endpoint definitions. Generated client methods use the paths, inputs,
and response choices defined by each endpoint. Your application supplies the runtime settings the client needs.

The supported client integration is xref:clients/spring-restclient.adoc[Spring RestClient]. Its guide covers setup,
generated methods, and runtime configuration.

When application source needs the generated client types, put the endpoints in a separate compiled API module. The
integration guide explains this setup.
