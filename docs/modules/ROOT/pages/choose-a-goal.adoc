= Choose a goal
:description: Find the guide for defining endpoints, generating documentation, or building clients and servers.
:page-aliases: capabilities.adoc

Start with the result you need. First define endpoints in Kotlin, then choose what to generate from them.

== Define endpoints

Read the xref:contracts/index.adoc[endpoint DSL guide]. To create API documentation or share an API definition with
other tools, follow the xref:documentation/openapi.adoc[OpenAPI guide].

== Build an HTTP client

Use the xref:clients/spring-restclient.adoc[Spring RestClient guide] to generate a typed client from your endpoints.

== Implement an HTTP server

Use the xref:servers/spring-webmvc.adoc[Spring WebMVC guide] to generate a server interface and connect it to your
application's handler.

== Understand the build

Read the xref:generation/index.adoc[generation guide] for how outputs are produced, then see the
xref:reference/maven.adoc[Maven reference] or xref:reference/gradle.adoc[Gradle reference] for build setup.
